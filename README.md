One word, 13 characters: the word an agent says when it has no idea what to do.

The entry:

> `Recalculating`

13 characters, one word, valid UTF-8 — inside the 99-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–99 characters, single word, non-whitespace, valid UTF-8) before and after writing.
